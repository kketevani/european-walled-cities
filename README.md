# European Walled Cities

**[Open the interactive map](https://kketevani.github.io/european-walled-cities/)**

An interactive, zoomable map of European cities listed as having defensive walls. Use the country dropdown to filter the 1,525 city-level entries.

## Data and scope

The map is based on Wikipedia’s [List of cities with defensive walls](https://en.wikipedia.org/wiki/List_of_cities_with_defensive_walls), geocoded at city level.
